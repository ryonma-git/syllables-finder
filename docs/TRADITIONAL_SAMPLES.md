# 多言語の伝承歌サンプル

内蔵サンプルは対応する10言語すべてに少なくとも1曲ずつある。今回追加した8曲は、版による違いがある伝承歌・古い童謡の**短い冒頭**を読解用に記録した。各語の意味、文の訳、音節、IPA、カタカナ読みは教材用の近似であり、歌手の発音や地域差を確定するものではない。音符は資料から照合していないため入力していない。既存のきらきら星、Mary Had a Little Lamb、Frère Jacques は音符付き。

中国語は上記譜面にある「好一朵茉莉花」で始まる伝承詞を使う。近年の「美丽的」を挟む版とは区別する。韓国語のアリランには地域ごとに多くの版があり、このサンプルは広く歌われるリフレインの一例である。
