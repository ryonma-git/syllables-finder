# 意味・訳・発音の自動補完とAI接続

歌詞を追加すると、未設定の単語の文脈に合う短い日本語の意味と、行全体の日本語訳を自動補完します。「音節に分ける」が有効なら、内蔵の英語発音辞書とAIでIPA・カタカナも補完します。音節を分けない場合も意味・訳は補完します。既存の曲には「未設定の意味・訳を補完」「未設定の発音を補完」を使います。

## 接続と優先順

ツールバーの「AI接続」で方式を設定します。

- 自動：発音はApple Foundation Models → このMacのOllamaモデル → 送信を許可したOpenAI互換API。意味・訳は導入済みQwen 3.5が選択対象にあれば先に使います。QwenがないMacはAppleFMから使えます。短い英語の単語訳の実機確認でAppleFMに代名詞の誤訳があり、Qwenで改善したための用途別の優先順であり、全言語・全入力での品質を保証しません。
- ローカルLLM優先：選択したOllamaモデルから試します。未選択なら導入済みQwenを優先します。
- API優先：キー・モデル・送信許可が設定されているAPIから試します。
- 辞書のみ：LLMにアクセスしません。内蔵発音辞書とMacで有効な辞書を使います。

AppleFMはmacOS 26以降の対応機種でApple Intelligenceが利用可能な場合に使用します。アプリの最低OSはmacOS 14を維持し、FoundationModelsをweak linkしています。対応しないMacでは残りの方式を利用します。他機種での実動作確認と、署名・公証済み配布は別途必要です。

AppleFMの利用可能表示と、短い構造化JSONを生成する「応答テスト」は別です。モデル一覧が取得できても推論成功とは扱いません。応答テストには歌詞を使用しません。接続成功も発音・翻訳の正確さを保証するものではありません。

Ollamaが動いていれば「モデルを追加」から任意のモデルをダウンロードできます。利用者が確認ボタンを押すまでダウンロードしません。Ollama自体の自動インストールや、既存モデルの削除は行いません。

APIはベースURL（例：末尾 `/v1`）、モデル名、キーを入力します。キーは接続先ごとにこのMacのキーチェーンへ保存し、曲ファイル・Git・UserDefaultsへ入れません。HTTPSを必須とし、localhostだけHTTPを許可します。リダイレクトで歌詞やキーを別の接続先へ送ることはありません。クラウドでの実接続確認には利用者自身のキーが必要です。

## 候補の適用と保全

AIの出力は語・音節の番号、IPAとカタカナの文字種、単語全体と各音節のIPAの一致を検査します。英語辞書にある語は辞書の発音とも照合し、対応できるIPAからはカタカナを組み立てます。AI候補の意味的な正しさを完全に判定するものではありません。

歌詞、音節ID、音符との対応、手修正は保持します。応答待ちに変更された単語へ古い結果を適用しません。新規入力時のみ、英語の隣接母音が別音節になる場合を辞書の音節数で補います。既存の音節数は変更しません。

進捗と使用中のモデルを表示し、中止・再確認ができます。一部の語の不正な応答で他の語を失わないよう個別に処理し、接続できないモデルは同じ実行の各行で繰り返し試しません。未解決の語は件数と語を表示します。取り消し・やり直し・接続設定の変更時には進行中の補完を中止します。

自動の意味補完は空欄のみが対象です。既存の意味・訳、手修正（意図して削除した空欄を含む）、解析待ちに変更された値は保持します。意味の失敗だけで発音補完を止めず、反映できた結果と残りの語数・行数を表示します。意味は読む画面とWord・PDFの単語訳・翻訳欄に反映します。

「意味を解析」は選択行の再解析用で、同じ接続設定を使用します。辞書モードでは単語の詳細に辞書定義を追加し、全文訳や手修正した意味を置き換えません。辞書定義だけでは文脈訳・全文訳が完成しないことを画面に表示します。定義の言語と収録範囲はMacで有効な辞書に依存します。

## 開発時の検証

通常の `native/scripts/swift-tool.sh test` は実ネットワークを使用せず、接続・API認証ヘッダー・無効な応答・バックエンド切替・同時編集保護を検証します。

任意の実機試験は `SINGING_TEST_APPLE_FM=1` と `SINGING_TEST_LOCAL_QWEN=1` を指定します。後者は現在、AppleFM優先のルーティングで合成英文の発音を検証します。ユーザーの歌詞は試験に使用しません。

意味・訳の実機試験は `SINGING_TEST_MEANINGS=1`。2行の合成英文について意味・訳の空欄、代名詞・冠詞、IDと発音の保持を確認します。`SINGING_TEST_MEANINGS_LOCAL=1` ではローカルLLM優先を明示できます。

参照：[Apple Foundation Models](https://developer.apple.com/documentation/foundationmodels/systemlanguagemodel)、[OpenAI互換のChat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)、[Ollamaのモデル追加API](https://docs.ollama.com/api/pull)。
