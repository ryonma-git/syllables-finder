# 英語の発音・カタカナ候補

## 使い方

新しい歌詞の入力では、英単語全体を同梱のCMU Pronouncing Dictionaryで照合します。
既存の文書では「読む」画面の **英語の発音を整える** を押します。
更新した語数、手修正を保持した語数、個別確認が必要な語を表示します。
操作は「編集 → 取り消す」で戻せます。

カタカナの共通基準は `are = アー`、`the = ザ`、通常の `-tion /ʃən/ = ション` です。
英語の音を日本語で近似する補助表記なので、IPAとは別に管理します。
`question` の `/tʃən/` など、異なる音まで一律に `/ʃən/` に変換しません。

## 辞書上の音節と歌唱上のまとまり

- `coming` は `/ˈkʌmɪŋ/`。「コウミング」の `/oʊ/` にはしません。
- `comin'` は語末を `/n/` にした形です。
- `creation` の通常の発音は `/kriˈeɪʃən/`。既定は `cre / a / tion` の3音節です。
- 利用者が `crea / tion` と明示した場合は、2つの**歌唱グループ**として
  `/kriˈeɪ/ + /ʃən/`、`クリエイ / ション` を付けられます。
  これは辞書上の音節数を2とする判断ではありません。

既存の音節数を自動で増減させません。音節ID・音符・音符への対応を維持します。
音節数を人が変更する従来の編集操作では、対応の再設定が必要になる場合があります。

## 手修正と不確かな語

- 手修正したIPA・読み・音節文字・強勢を保持します。
- 音素やモーラを明示している音節は自動修正しません。
- 境界の修正が手修正済みの読みと衝突する場合は、その語全体を保持し、個別確認に回します。
- `wind` のように文脈で読みが変わる語は、現在の発音が辞書の候補に一致すれば採用し、
  一致しなければボタンの自動処理では決めません。
- 辞書は米語です。歌手固有の発音、連結、弱形や方言を音声から認識する機能ではありません。
  カタカナ変換と綴りの区切りにも規則による近似が含まれます。

## ローカルLLMとの役割分担

`OllamaPronunciationProvider` は最初に辞書を適用します。
辞書だけで処理できる行ではモデルへの通信を行いません。
未解決語は文全体と辞書の候補をローカルモデルに渡し、単語全体のIPAを先に決めてから
既存の音節IDへ配分させます。

応答は、ID・個数に加えて、単語全体のIPAと音節順に連結したIPAの一致、辞書候補との一致、
IPAの文字・空欄・長さ、カタカナの文字種を確認します。不適合な応答は文書へ適用しません。
辞書外の語について、形式検査だけで発音の正しさを保証することはできません。

  辞書本文は改変していません。

利用時に外部の辞書サービスへの通信はありません。
