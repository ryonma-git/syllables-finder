# 英語の発音・カタカナ候補

## 使い方

新しい歌詞の入力では、選んだ発音基準の辞書で英単語全体を照合します。
既存の文書では「読む」画面の **英語の発音を整える** を押します。
更新した語数、手修正を保持した語数、個別確認が必要な語を表示します。
操作は「編集 → 取り消す」で戻せます。

カタカナの共通基準は `are = アー`、`the = ザ`、通常の `-tion /ʃən/ = ション` です。
英語の音を日本語で近似する補助表記なので、IPAとは別に管理します。
`question` の `/tʃən/` など、異なる音まで一律に `/ʃən/` に変換しません。

## 英国式／米国式の選択

新しい曲の「歌詞を追加」では英国式が初期値です。米国式にも変更できます。選択は曲に保存され、既存曲への追加はその曲の基準を使います。「読む」画面で曲全体の基準を切り替えられます。旧形式の保存ファイル（基準の指定なし）は従来の米国式として扱い、開くだけでは変換しません。

米国式は内蔵CMUdict、英国式は確認済みの基本語の発音を使います。英国式の内蔵辞書は限定的です。辞書にない語を米国式の値で代用せず、設定されたApple FM・ローカルモデル・APIの補完に渡します。AIが使えない場合、対応外の語は未設定として手入力・確認が必要です。英国式の包括的な辞書を搭載しているわけではありません。

基準の切り替え時は、自動生成したIPA・カタカナ・強勢を更新します。辞書で決まらない語は空欄になり、「未設定の発音を補完」でAIを利用できます。手修正や詳細な音素・モーラ情報のある単語はそのまま保持します。歌詞、音節ID、音符、音符との対応、意味・訳は変更しません。取り消しに対応します。

英国式の例は mountain /ˈmaʊntɪn/ → マウン・ティン、falling /ˈfɔːlɪŋ/ → フォー・リング、from /frɒm/ → フロムです。fromには弱形 /frəm/ もあります。新規入力では強形を使い、すでに選ばれた弱形や手修正は尊重します。

参照した発音辞書：[mountain](https://www.collinsdictionary.com/dictionary/english/mountain)、[fall](https://www.collinsdictionary.com/dictionary/english/fall)、[from](https://www.collinsdictionary.com/dictionary/english/from)、[gone](https://www.collinsdictionary.com/dictionary/english/gone)。カタカナはアプリの歌唱補助用の近似表記です。

## 辞書上の音節と歌唱上のまとまり

- `coming` は `/ˈkʌmɪŋ/`。「コウミング」の `/oʊ/` にはしません。
- `comin'` は語末を `/n/` にした形です。
- `creation` の通常の発音は `/kriˈeɪʃən/`。既定は `cre / a / tion` の3音節です。
- 米語辞書を利用し、利用者が `crea / tion` と明示した場合は、2つの**歌唱グループ**として
  `/kriˈeɪ/ + /ʃən/`、`クリエイ / ション` を付けられます。
  これは辞書上の音節数を2とする判断ではありません。

既存の音節数を自動で増減させません。音節ID・音符・音符への対応を維持します。
音節数を人が変更する従来の編集操作では、対応の再設定が必要になる場合があります。

## 手修正と不確かな語

- 手修正したIPA・読み・音節文字・強勢を保持します。
- 音素やモーラを明示している音節は自動修正しません。
- 境界の修正が手修正済みの読みと衝突する場合は、その語全体を保持し、個別確認に回します。
- `wind` のように文脈で読みが変わる語は、現在の発音が辞書の候補に一致すれば採用し、
  一致しなければボタンの自動処理では決めません。
- 歌手固有の発音、連結、弱形や方言を音声から認識する機能ではありません。
  カタカナ変換と綴りの区切りにも規則による近似が含まれます。

## AIとの役割分担

`OllamaPronunciationProvider` は最初に辞書を適用します。
辞書だけで処理できる行ではモデルへの通信を行いません。
未解決語は文全体と発音基準を設定されたモデルに渡し、単語全体のIPAを先に決めてから
既存の音節IDへ配分させます。辞書の候補は回答の検証に使い、順序による偏りを避けるためモデルには提示しません。

応答は、ID・個数に加えて、単語全体のIPAと音節順に連結したIPAの一致、辞書候補との一致、
IPAの文字・空欄・長さ、カタカナの文字種を確認します。不適合な応答は文書へ適用しません。
AIへは発音基準を明示し、単語全体のIPAと音節ごとのIPAの連結を母音の種類・長さを含めて照合します。カタカナは対応するIPAから生成します。解釈できないIPA、既知の辞書候補との矛盾、英国式指定で明確な米国式の /oʊ/・r音化母音・非母音前のrは採用せず、別の接続先での補完または未設定に戻します。生成待ちの間に基準が変わった結果も反映しません。

辞書外の語について、形式検査だけで発音の正しさを保証することはできません。

## 出典と配布

- [CMU Pronouncing Dictionary](https://github.com/cmusphinx/cmudict)
  — 語全体の米語ARPAbet。固定リビジョン・SHA-256・ライセンスは
  `native/Sources/SongCore/Resources/CMUDict/` に収録しています。
  辞書本文は改変していません。
- [Oxford: creation](https://www.oxfordlearnersdictionaries.com/definition/english/creation)
- [Oxford: come / coming](https://www.oxfordlearnersdictionaries.com/definition/english/come_1)

SwiftPMのリソースとして辞書を組み込み、`build-app.sh` がアプリのResourcesへ複製します。
利用時に外部の辞書サービスへの通信はありません。

## ローカル生成API

ローカル生成APIの入力JSONでは `"englishPronunciation": "british"` または `"american"` を指定できます。省略時は既存APIとの互換性のため米国式です。
