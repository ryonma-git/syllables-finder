# 歌唱練習シート iPad版

iPadOS 16以降のiPadで動く、授業・研修向けの教材作成アプリです。英語発音辞書と教材画面をアプリに同梱しています。

## 教材を作る

1. 「曲名」「歌詞」に入力し、「教材を作成」をタップします。歌詞の改行が教材の1行になります。
2. プレビューの単語をタップすると、音節、発音記号、カタカナ読み、意味を編集できます。「行の訳を入力」から日本語訳も加えられます。
3. 「PDFを共有」から「ファイルに保存」を選ぶと、A4のPDFを保存できます。「印刷・PDF」からiPadの印刷画面を開けます。
4. 「教材データを保存」で編集用JSONを書き出し、「教材を開く」で続きから編集できます。

英語の辞書はオフラインで動きます。「OpenAIで補完…」を選んだ場合はインターネット接続と利用者ご自身のOpenAIプロジェクトキーを使います。アプリはキーを今回の処理の間だけメモリに保持します。

## 主催者がビルド・配布する

1. MacのXcodeで `SingingWorksheet.xcodeproj` を開きます。
2. シミュレータで試す場合は、実行先にiPadを選び、Runを実行します。主催者用ソースZIPの `Web` フォルダには辞書と教材画面が入っています。リポジトリで直接ビルドする場合は共有Web版の辞書を自動生成します。
3. 実機で使う場合は、ターゲットの「Signing & Capabilities」で利用するTeamとそのチームで使えるBundle Identifierを設定し、iPadを実行先に選びます。
4. 参加者のiPadへTestFlightで配布するには、Apple Developer Programのチームで署名してArchiveし、App Store Connectへアップロードします。外部テストはAppleの審査を経て招待リンクを配布できます。[AppleのTestFlight案内](https://developer.apple.com/testflight/)

主催者用の `unsigned.xcarchive` は署名前の実機向けビルドです。参加者が端末にインストールするには、主催者による署名・配布手続きが必要です。
